# Сайт Елены Синицыной

Мини-лендинг (страница со всеми ссылками) юриста Елены Синицыной: единое пособие, выплаты семьям, консультации.

Адрес: https://sinitsyna-pravo.github.io
Хостинг: GitHub Pages, ветка `main`, корень репозитория. Любой push в `main` публикуется сам за 1–2 минуты.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Вся страница: разметка, стили и иконки в одном файле. Без фреймворков и сборки. |
| `og.png` | Картинка превью ссылки в Telegram и WhatsApp, 1200×630. |
| `favicon.svg` | Значок вкладки браузера. |
| `apple-touch-icon.png` | Значок на экране телефона, 180×180. |
| `.nojekyll` | Отключает обработку Jekyll на GitHub Pages. |
| `design/og.html`, `design/icon.html` | Исходники картинок: открыть в Chrome и снять скриншот 1200×630 и 180×180. |

## Дизайн

- Фон `#000000`, тёмно-синий `#0A1426` / `#0E1B33`, золото `#C9A45C` (светлое `#ECD496`, тёмное `#A07F3E`), текст `#F5F0E6`, второстепенный `#A7A399`.
- Шрифты Google Fonts: Cormorant Garamond 500/600 (имя, заголовки), Montserrat 400/500/600 (текст, кнопки).
- Сначала телефон: контент до 460 px по центру, кнопки от 74 px в высоту.

## Свой домен

1. У регистратора добавить A-записи: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`; для `www` добавить CNAME на `sinitsyna-pravo.github.io`.
2. Settings → Pages → Custom domain → вписать домен, затем включить Enforce HTTPS.
3. Заменить адрес в `index.html` (canonical, og:url, og:image) и надпись на `og.png` (`design/og.html`).

Аудитория в России: хостинг должен открываться без VPN. Cloudflare не подходит, российские провайдеры его замедляют с 2025 года.
